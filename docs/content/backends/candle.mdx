# `ort-candle`
`ort-candle` is an [alternative backend](/backends) for <Ort/> based on [🤗 Hugging Face `candle`](https://github.com/huggingface/candle).

## Supported APIs
- ✅ `ort::init`
- 🔷 `ort::environment::EnvironmentBuilder`
    - `EnvironmentBuilder::build`
    - `EnvironmentBuilder::with_global_thread_pool` (accepted, but has no effect)
- ✅ `ort::memory::Allocator`
    - Only CPU allocations are supported.
- ✅ `ort::memory::MemoryInfo`
- 🔷 `ort::session::Session`
    - `Session::builder`
    - `Session::inputs`, `Session::outputs`
    - `Session::allocator`
    - `Session::metadata`
    - `Session::run`
    - `Session::run_with_options`
    - `Session::create_binding`, `Session::run_binding`
- ✅ `ort::session::RunOptions`, `ort::session::OutputSelector`
    - `RunOptions::terminate` only takes effect if called before the run.
- 🔷 `ort::session::builder::SessionBuilder`
    - `SessionBuilder::new`
    - `SessionBuilder::commit_from_file`
    - `SessionBuilder::commit_from_memory`
    - `SessionBuilder::commit_from_memory_directly`
    - `SessionBuilder::with_initializer`, `SessionBuilder::with_external_initializer`
    - `SessionBuilder::with_dimension_override`, `SessionBuilder::with_dimension_override_by_denotation`
- ✅ `ort::value::DynValue`, `ort::value::DynValueRef`, `ort::value::DynValueRefMut`
    - Only `Tensor` types are supported.
- ✅ `ort::value::Tensor`, `TensorRef`, `TensorRefMut`, etc.
    - String tensors are not supported.
- ✅ `ort::value::ValueType`

## Usage

<Steps>

### Install `ort-candle`
```toml filename="Cargo.toml"
[dependencies]
ort-candle = "0.6.0+0.11.1"
...
```

### Enable the `alternative-backend` feature
This instructs <Ort/> to not try to download/link to ONNX Runtime.

```toml filename="Cargo.toml"
[dependencies.ort]
version = "=2.0.0-rc.15"
default-features = false # Disables the `download-binaries` feature since we don't need it
features = [
    "std",
    "ndarray",
    "alternative-backend"
]
```

### Initialize the backend
Use [`ort::set_api`](https://docs.rs/ort/latest/ort/fn.set_api.html) to use the crate's API implementation.

```rs filename="main.rs"
fn main() {
    // This must run as early in your application as possible - before you ever use `ort`!
    unsafe { ort::set_api(ort_candle::api()) };
}
```

### Done!

</Steps>
